# Wanderlust Launcher

Открытый исходный код лаунчера проекта **Wanderlust** — кастомного лаунчера
Minecraft. Код опубликован, чтобы каждый игрок мог убедиться, что лаунчер
безопасен: никакой слежки, майнинга и скрытых действий здесь нет.

## Что делает лаунчер

Ставит и запускает игру «под ключ»:
- скачивает Java (OpenJDK Temurin) и NeoForge нужной версии;
- скачивает и держит в актуальном состоянии моды сборки через **packwiz**;
- запускает игру и умеет обновлять сам себя.

## Чему можно доверять (и как это проверить в коде)

- **Единственный адрес, откуда лаунчер берёт данные** — публичный манифест
  проекта (см. `MANIFEST_SOURCE` в [`src-tauri/src/lib.rs`](src-tauri/src/lib.rs)).
  Всё остальное качается только с официальных источников: Adoptium (Java),
  maven.neoforged.net (NeoForge), CDN Modrinth и GitHub (моды).
- **Все загрузки проверяются по SHA-256/SHA-1** перед использованием
  (см. [`src-tauri/src/downloader.rs`](src-tauri/src/downloader.rs)).
- **Никакой телеметрии.** Лаунчер не собирает и никуда не отправляет
  персональные данные.
- **Свои моды не удаляются.** packwiz управляет только файлами сборки;
  моды, добавленные игроком вручную, остаются на месте.
- Все файлы лежат в одной папке `%APPDATA%/Wanderlust/` — удаляется одним
  движением.

## Сборка из исходников

Требуется [Rust](https://rustup.rs/) и [Tauri CLI](https://tauri.app/):

```bash
cargo install tauri-cli
cd src-tauri
cargo tauri build
```

Готовый `Wanderlust.exe` появится в `src-tauri/target/release/`.
Для запуска в режиме разработки: `cargo tauri dev`.

## Структура

- `frontend/` — интерфейс (HTML/CSS/JS без сборщика).
- `src-tauri/src/` — бэкенд на Rust: установка JRE/NeoForge, синхронизация
  модов, запуск игры, самообновление.
- `dev/` — локальные файлы для разработки.
